# InvictaTill Browser 2.12.1

## Sidebar

- ChatGPT opens in the same sidebar as WhatsApp. Select its icon in the app rail or press `Ctrl+Shift+G`.
- Select **+** to add a website. The browser saves the shortcut and keeps the page open when you switch between sidebar sites.
- Use the panel header to reload the page, open it in a full tab, or remove an added website.

## Downloads

- Aligned file details, warnings, progress bars, and action buttons in the Downloads popup and full Downloads view.
- The Downloads popup stays accessible while a website is open in the sidebar.

Installed copies can check for updates under **Browser tools → Settings → Browser updates**. Portable users can download the new portable executable.
