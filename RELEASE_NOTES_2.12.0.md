# InvictaTill Browser 2.12.0

## ChatGPT

- InvictaTill AI has been replaced with ChatGPT. Open it from the left rail, new-tab shortcuts, browser menu, command palette, or Settings. You can also press `Ctrl+Shift+G`.
- ChatGPT opens in a regular tab in the current workspace. Choose **Log in** on the official ChatGPT site to use your account.
- For writing help, select text and choose **Copy selection and open ChatGPT**, then paste what you want to share. Chromium spellcheck is available in supported text fields.

## Browser improvements

- Refined desktop and compact layouts, dark theme contrast, address suggestions, dialogs, and tab controls.
- Moved the task scanner and 24-hour activity report into **Browser tools**.
- Replaced the idle-tab sleep indicator with a setting for Chromium background throttling.
- Fixed password CSV import, Reading Mode, focus timer transitions, workspace extension popups, and browser update error handling.

Installed copies can check for updates in **Browser tools → Settings → Browser updates**. Portable users can download the updated portable executable.
