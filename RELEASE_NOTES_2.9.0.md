# InvictaTill Browser 2.9.0

A calmer space to browse and work. This update replaces the dense, dark interface with a soft light theme, sage accents, quieter surfaces, and more breathing room.

- The new tab centers search and shortcuts. Expand **Bookmarks & recent pages** when you want to return to saved or recent browsing.
- The toolbar has fewer visible controls. Open **Menu → Page & browser tools** for screenshots, split view, mute, passwords, extensions, find, and printing. Tab management stays together under **Tab actions**.
- The AI panel starts with a shorter welcome. Expand **Page & writing tools** for page summaries, explanations, tasks, email actions, and work reports. Page access remains off by default.
- Workspaces, WhatsApp, focus sessions, tasks, history, downloads, passwords, and existing keyboard shortcuts remain available. History, focus, tasks, and command search also have direct menu entries.
- Menu keyboard navigation skips collapsed controls, supports opening and closing tool groups, and returns focus when the menu closes. Mute and split-view labels show the current action.
- The menu closes before screenshots, split view, password management, and extension actions open.

This release is distributed without a publicly trusted Authenticode signature. Windows may display an **Unknown publisher** or Microsoft Defender SmartScreen warning. Download only from the official InvictaTill Browser GitHub release page.
